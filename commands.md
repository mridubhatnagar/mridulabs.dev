# Frequently Used Commands

## Resume

### Compile
```bash
# Job application version (with phone)
npm run resume

# Public website version (no phone)
npm run resume:public
```

### Open PDF
```bash
# Job application version
xdg-open resume-typst/cobalt-cv/mridu-resume.pdf

# Public version
xdg-open resume-typst/cobalt-cv/mridu-bhatnagar-resume.pdf
```

## Dev Server
```bash
npm run dev
```
